# Career Form MVP

Конструктор форм отклика для карьерной платформы с встроенной аналитикой оттока

## запуск

Требуется Node.js 20+. Для запуска достаточно ровно двух команд из корня репозитория:

```bash
# 1. Установка зависимостей и автоматическая сборка фронтенда (через postinstall)
npm install

# 2. Запуск единого сервера (API + раздача статического фронтенда)
npm start
```
*После запуска приложение доступно на `http://localhost:3000` (порт настраивается через `PORT`).*

## Ключевые архитектурные решения

### 1. Динамическая валидация на сервере
Бэкенд не хранит жесткую схему ответов. При `POST /api/forms/:uuid/responses` сервер:
1. Загружает метаданные полей конкретной формы из БД.
2. Динамически генерирует Zod-схему (учитывая типы полей и флаг required).
3. Валидирует входящий payload против этой схемы.
   Результат: Гарантия отсутствия мусора в БД и строгая типизация без хардкода структур.

### 2. Надежный трекинг оттока
Реализован через `navigator.sendBeacon` и событие `visibilitychange`.

Обычные fetch-запросы отменяются браузером при закрытии вкладки, поэтому использван
`sendBeacon`, который гарантирует доставку данных фоном. 
### 3. Асинхронная работа с SQLite (libSQL)
Используется `@libsql/client` вместо стандартного синхронного `better-sqlite3`.
* При инициализации принудительно включается режим WAL (Write-Ahead Logging).
* Результат: Читатели (админка) не блокируют писателей (студенты), что предотвращает ошибки SQLITE_BUSY при конкурентной нагрузке.
