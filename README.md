# Сервис кастомных форм отклика (MVP)

No-code конструктор форм для карьерной платформы с глубокой аналитикой поведения пользователей. Решает проблему зависимости менеджеров от разработчиков при создании форм и позволяет выявлять причины низкой конверсии (оттока) студентов.

## Ключевой функционал

### Для менеджеров (Административная панель)
- **No-code конструктор:** Визуальное добавление полей (текст, выпадающий список, чекбокс) без написания кода.
- **Мгновенная публикация:** Генерация уникальной публичной ссылки одним кликом.
- **Валидация:** Возможность отмечать поля как обязательные.

### Для студентов (Публичная форма)
- **Динамический рендеринг:** Форма строится на лету на основе JSON-схемы из базы данных.
- **Клиентская валидация:** Проверка обязательных полей перед отправкой.
- **UX:** Адаптивный интерфейс на Tailwind CSS.

### Системные возможности и Аналитика
- **Трекинг вовлеченности:** Автоматическая запись событий `focus` (начало заполнения) и `blur` (завершение ввода) для каждого поля.
- **Надежное отслеживание оттока (`abandon`):** Использование `navigator.sendBeacon` гарантирует отправку события закрытия вкладки даже при обрыве соединения.
- **Аналитика "последнего касания":** Специальный SQL-запрос с оконными функциями определяет, на каком именно поле студент закрыл форму, позволяя менеджеру найти "узкое место".
- **High-load оптимизация:** Пакетная запись аналитики (Batch Insert) с принудительным немедленным сбросом буфера при событии `abandon`.

---

##  Технческий стек

- **Backend:** Node.js 20+, Express, TypeScript, Zod (валидация схем).
- **Database:** SQLite через асинхронный драйвер `@libsql/client` (не блокирует Event Loop).
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, React Router DOM.
- **Инфраструктура:** Полная автономность (нет внешних API, облачных СУБД или ключей).

## Требования к окружению

- **Node.js:** версии 20 или новее.
- **ОС:** Windows, macOS или Linux.
